# Toll Gate System

This project demonstrates a toll gate system and its operating workflow.

- `cranes_1sst_intership_certificate.png` - Internship certificate.

## Overview

The toll gate system is designed to demonstrate vehicle identification, toll collection, and gate access control. The implementation details are provided in the project PDF, and the video shows the system demonstration.
